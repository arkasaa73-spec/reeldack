ReelDack 🎬

ReelDack - мобильное приложение на Flutter для просмотра информации о фильмах и поиска фильмов через внешний API.

Приложение содержит список фильмов с постерами, описанием, жанром, годом выпуска и рейтингом. Пользователь может открыть подробную информацию о фильме, поставить лайк и сохранить его состояние между запусками приложения.

Возможности

* Просмотр списка фильмов в виде карточек
* Просмотр подробной информации о фильме
* Поиск фильмов через OMDb API
* Отображение результатов поиска из API
* Добавление фильмов в избранное с помощью лайков
* Сохранение лайков на устройстве
* Поддержка русского и английского языков
* Обработка ошибок API и тайм-аута запроса
* Обновление интерфейса без перезапуска приложения

API

Для поиска используется OMDb API (Open Movie Database).

Запрос отправляется через HTTP и содержит поисковый запрос пользователя:

https://www.omdbapi.com/?s=QUERY&apikey=API_KEY

Полученный JSON преобразуется сначала в DTO-модель, а затем в модель фильма Show.

Работа с API реализована в show_repository.dart через OmdbShowRepository. (GitHub)

🛠 Технологии

* Flutter — разработка мобильного приложения
* Dart — язык программирования
* flutter_bloc — управление состоянием
* HTTP — выполнение запросов к OMDb API
* SharedPreferences — локальное хранение состояния лайков
* Flutter Localizations — поддержка русского и английского языков

Основные зависимости проекта указаны в pubspec.yaml. (GitHub)

📱 Основные экраны

Главный экран

Отображает список фильмов с постерами, кратким описанием и возможностью поставить лайк.

Экран фильма

Показывает подробное описание, год выпуска, жанр, рейтинг и состояние лайка.

Поиск

Позволяет найти фильм по названию с помощью OMDb API.

💾 Локальное хранение

Для сохранения лайков используется SharedPreferences. Состояние каждого фильма сохраняется на устройстве и восстанавливается после повторного запуска приложения. (GitHub)

🌍 Локализация

Приложение поддерживает два языка:

* 🇷🇺 Русский
* 🇬🇧 English

Переключение языка доступно непосредственно из интерфейса приложения. (GitHub)
